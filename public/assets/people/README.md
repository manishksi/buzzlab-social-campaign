# People

Baked from MakeHuman's CC0 assets (base mesh, macro targets, default skeleton and weights, eyes,
eyebrows, eyelashes, teeth, hair and clothes from the MakeHuman system asset pack). See
https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md — the assets are released
under CC0 1.0. No MakeHuman program code is used; the baking script lives outside the site.

- `male.json` / `male.bin`, `female.json` / `female.bin`: one body per sex with every hair style,
  outfit and pair of shoes fitted to it, skinned to one simplified skeleton.
- `tex/`: skin, eyes, brows, lashes, teeth, hair and clothing textures (WebP).

Loaded by `src/components/machine/people.ts`.
